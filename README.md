# PYQ Finder - MBBS (v7)
Offline Android app: search topics, lectures, subjects or PYQs and see matching university questions, the PrepLadder lectures covering them, and source papers.
Everything is in this one flat folder. See HOW-TO-UPLOAD.txt to build the APK on GitHub.
Data: 618 lectures, 1,257 unique PYQs (1,434 paper x question slots), 139 papers.
To preview in a browser just open index.html.
